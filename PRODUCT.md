# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Основной пользователь — Vue 3 разработчик, который хочет взять готовую библиотеку компонентов и внедрить её в свой проект: понять компоненты по живым примерам, настроить тему под свой дизайн, включить одно или несколько дизайн-систем в одном проекте.
- Публичная open-source аудитория: dotdev станет публичным пакетом, поэтому пользователи — внешние разработчики, а не внутренняя команда.

## Product Purpose

Публичная open-source Vue 3 библиотека компонентов (`ui-kit`) с собственным сайтом документации. Цель — дать разработчикам чистый и гибко настраиваемый набор компонентов (BEM-методология + Tailwind CSS, без CSS-in-JS), который можно безболезненно встроить в проект и адаптировать под его дизайн, в том числе через несколько namespace в одном проекте. Документация собирается собственным фреймворком `studio` (живые примеры, плейграунды, DocPage), плюс идут пакеты `icons` и `theme`.

## Positioning

Чистая и гибко настраиваемая библиотека, сочетающая BEM-методологию и Tailwind CSS без CSS-in-JS, с поддержкой нескольких namespace в одном проекте — это позволяет апрувить (поэтапно внедрять) новый дизайн безболезненно, не ломая существующий.

## Operating Context

- Приложение — это сам сайт документации: сайдбар с меню компонентов, шапка с поиском и ⌘K, роут Dashboard, тёмная/светлая схема.
- Состав `ui-kit`: avatar, button, checkbox, floating, group, icon, icon-button, input, listbox, menu, radio, scroll-area, select, select-button, switch, tag, textarea, transition-presence, ui-kit-provider.
- `studio`: фреймворк для документации — `defineExample`, `DocPage`, плейграунды; страницы компонентов генерируются из `docs/examples/*.vue` через `import.meta.glob`.
- `icons`: собственный набор SVG-иконок, подключаемый через плагин Vite.
- `theme`: стили на CSS-токенах (oklch-палитра нейтралей), DSL `defineSheet`/`defineStyleSheet`, шрифты Plus Jakarta Sans + JetBrains Mono.

## Capabilities and Constraints

- Подтверждено: Vue 3 + TypeScript + Vite; без CSS-in-JS (стили — Tailwind-утилиты + CSS-токены); BEM-методология; несколько namespace на проект; собственная система тем; пакет иконок; фреймворк документации `studio`.
- Терминология: namespace, theme, sheet, studio, defineExample, DocPage.
- Не решено: механика публикации пакета (npm-имя, версионирование, чейнджлоги), лицензия, целевая матрица браузеров, требования доступности.

## Brand Commitments

- Имя: dotdev; логотип — точка внутри круга с галочкой, логотип-слово «Dot.Dev»; тег версии v0.1.0.
- Позиционные обязательства (со слов владельца): «чистая и гибко настраиваемая библиотека», сочетание BEM и Tailwind, «несколько namespace в одном проекте», «без CSS-in-JS».

## Evidence on Hand

- Репозиторий: рабочий сайт документации, ~19 компонентов с примерами, система тем, пакет иконок.
- Отсутствует и не должно выдумываться: внешние отзывы, клиенты, кейсы, press, метрики внедрения.

## Product Principles

- Чистота по умолчанию, гибкость по требованию: компонент прост из коробки и глубоко настраивается, когда нужно.
- Стили — только CSS: никакого CSS-in-JS; Tailwind-утилиты и CSS-токены.
- Namespace-first: несколько дизайн-систем сосуществуют в одном проекте, внедрение должно быть безболезненным.
- BEM + Tailwind работают вместе: методология и утилиты не конфликтуют.
- Документировано и демонстрируемо: каждый компонент идёт с живыми примерами через `studio`.

## Accessibility & Inclusion

- Отдельного требовательного стандарта не установлено. В коде есть поддержка клавиатурной навигации (`useKeyboardNavigation`), поиск по ⌘K; конкретный стандарт (WCAG и т. п.) — открытый вопрос.
